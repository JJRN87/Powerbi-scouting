# Organización del proyecto

Proyecto personal desarrollado mediante entregas pequeñas: datos, rankings, informe y revisión de resultados. Cada revisión parte de una pregunta concreta y deja sus decisiones y comprobaciones documentadas.

## Uso de las herramientas

| Herramienta | Función |
|---|---|
| Jira | Tareas, criterios de aceptación, estado y enlaces a resultados. |
| Confluence | Objetivo, método y decisiones del proyecto. |
| GitHub | Código, cambios, documentación pública y capturas. |

El tablero utiliza Por hacer, En curso y Listo. Las tareas implementadas pasan a Listo cuando sus criterios tienen evidencia. Las propuestas no ejecutadas se identifican como futuras, sin contarlas como trabajo terminado.

Se han utilizado backlog, criterios de aceptación, revisión de resultados y entregas iterativas. Son prácticas compatibles con Scrum. No se han formalizado sprints ni las responsabilidades y eventos de un equipo Scrum.

## Entregas

| Entrega | Resultado |
|---|---|
| Datos y limpieza | Descarga reproducible, relaciones por ID, reglas y controles de totales. |
| Rankings y visor | Siete perfiles, pesos editables y detalle de contribuciones. |
| Power BI | Informe interactivo y 1.359 comparaciones Python–DAX sin diferencias. |
| Perfiles | Revisión de atributos, escenarios y decisión de conservar los pesos base. |
| Partidos y contexto | Pruebas de estabilidad y ajustes exploratorios por equipo. |
| Cierre | Presentación personal, explicación sencilla y alcance de futuras ampliaciones. |
| Publicación web | Demo en GitHub Pages, validación del visor desplegado y cierre público. |

## Cierre del proyecto

El análisis histórico terminó el 17/10/2026 con diez tareas completadas. El 21/10/2026 se añade [SCOUT-12](https://jjrn87.atlassian.net/browse/SCOUT-12), demo pública y cierre, en Listo. El total es de once tareas terminadas, sin trabajo pendiente dentro de esta entrega. [SCOUT-7](https://jjrn87.atlassian.net/browse/SCOUT-7) recoge la revisión de perfiles y [SCOUT-8](https://jjrn87.atlassian.net/browse/SCOUT-8), el análisis de partidos y contexto.

SCOUT-12 enlaza la [demo pública](https://jjrn87.github.io/Powerbi-scouting/), sus criterios cumplidos y las comprobaciones. Confluence incorpora el mismo cierre y el enlace de acceso. GitHub conserva el resumen, el backlog y las capturas para consultarlos sin una cuenta de Atlassian.

[SCOUT-11](https://jjrn87.atlassian.net/browse/SCOUT-11) queda aplazada como propuesta futura para evaluar datos actuales. Se conserva en Por hacer con su alcance explícito; no bloquea el cierre de esta versión ni se marca como completada.

El [backlog público](../backlog.json) distingue estado de ejecución y alcance del cierre. La [propuesta de ampliación](../FUTURO.md) reúne esa idea y las demás mejoras posibles.
